How I test

  1. Understand the requirement. What should happen, and just as important, what shouldn't.
  2. Write the cases. Happy path first, then the edges and the wrong inputs.
  3. Run them. Through the UI, through the API in Postman, and in the database with SQL.
  4. Report clearly. Steps, expected vs actual, severity and priority. No guesswork for the developer.
  5. Retest. Confirm the fix, then run regression so nothing else broke.
